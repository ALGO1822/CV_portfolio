# Portfolio · Favour Abayomi

Personal portfolio website for Favour Abayomi, Flutter developer. Built with vanilla HTML, CSS, and JavaScript with zero frameworks or build tools.

Live site: [devfavour-portfolio.vercel.app](https://devfavour-portfolio.vercel.app)

## Overview

A lightweight, single-page portfolio containing:
- **Work experience**: Student management system built with Flutter and Supabase.
- **Projects**: Showcase of Flutter apps (Split Bill, Stepwise, AI Vocabulary Builder, StoreKeeper, Fripto, Bicycle UI).
- **Interactive bento photo grid**: 6x3 cell layout with keyboard, mouse, and touch expand/pin animations.
- **Interactive features**: Hover text scramble on project titles, ASCII background screensaver, and theme switcher.

## Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, custom properties, calc())
- Vanilla JavaScript

## Running Locally

Clone the repository and run any local HTTP server:

```bash
git clone https://github.com/ALGO1822/CV_portfolio.git
cd CV_portfolio

# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve .
```

Then open `http://localhost:8000` in your browser.
